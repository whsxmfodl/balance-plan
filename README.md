# 밸런스 플랜

[공개 사이트](https://whsxmfodl.github.io/balance-plan/) · [소스 저장소](https://github.com/whsxmfodl/balance-plan)

18~64세 성인을 위한 무료 웰니스 계획 도구입니다. 회원가입·서버·유료 API·외부 라이브러리가 없습니다. 모든 계산은 방문자의 브라우저에서 실행됩니다.

## 사용 흐름

1. 목표, 나이·키·현재 체중, 가능한 시간과 운동 방식을 입력합니다. 목표 체중과 체성분은 비워도 됩니다. 실제 건강 수치를 예시값으로 미리 채우지 않습니다.
2. 날짜별 시작 계획, 동작·횟수·휴식과 이유를 확인합니다. 근력·매트 운동에는 회복일이 있고, 운동 가능 시간은 채워야 할 분량이 아니라 상한입니다.
3. 바쁜 날에는 10분 계획으로 전환하고 완료를 체크합니다.
4. 집밥·외식·편의점 식사 예시에서 피할 식품을 제외하고 단백질 식품을 바꿀 수 있습니다. 실제로 먹은 구성과 평소 대비 양을 체크하면 다음 한 끼의 선택을 안내합니다.
5. 원할 때만 **이 기기에 기억하기**를 누릅니다. 이후 입력과 완료·10분 전환을 같은 브라우저에서 이어갈 수 있습니다.

## 정확도와 안전 범위

- `catalog.mjs`에 공식 근거 링크, 연구의 적용 범위, 제품이 정한 시작 규칙을 나눠 기록했습니다. 이는 의료 처방이나 개인별 효과가 검증된 추천 모델이 아닙니다.
- 체성분은 키·체중·푸시업·사진으로 추정하지 않습니다. 골격근량과 체지방을 제외한 체중의 모순을 검사합니다.
- 임의의 주간 감량 속도를 넣어 예상 도착 날짜를 보여주지 않습니다. 사용자가 두 시점의 주간 평균 체중을 입력한 경우에만 관찰된 속도가 유지된다는 조건부 계산을 제공합니다. 정체기·체수분·개인 생리 변화를 모델링한 예측이 아닙니다.
- 푸시업 정보는 상체 운동 변형에만 사용합니다. 처음·복귀 사용자의 러닝 구간은 매일 반복되지 않습니다. 근육 목표 숫자가 크다고 자동으로 운동량을 크게 늘리지 않습니다.
- 근력 템플릿은 시작용 예시이며 각자의 모든 근육군·장비·기술을 완전히 평가하지 않습니다. 동작 교육과 개별 부하 조절은 대면 지도가 더 적합합니다.
- 65세 이상·저체중 범위·건강상 주의·서비스 범위를 벗어나는 목표는 자동 계획을 보류합니다. 15% 체지방률 목표와 25% 체중 변화 제한 등은 보수적인 제품 정책이며 보편적인 의학적 경계가 아닙니다.
- 알레르기 안전을 보장하지 않습니다. 식품 제외는 예시의 재료 수준이고 가공품·소스·교차접촉·목록 밖의 알레르기를 판별하지 못합니다.
- 음식 사진은 로컬 미리보기만 제공합니다. 자동 영양 분석, 신체 사진·영상 분석, 칼로리·목표 지연 날짜 추정은 구현하지 않았습니다.

## 개인정보와 비용

- 건강정보·사진을 서버나 외부 AI에 전송하지 않습니다. CSP는 연결 요청과 폼 전송을 차단합니다. 외부 출처 링크는 방문자가 선택할 때만 새 탭에서 열립니다.
- 기본 상태에서는 건강정보를 자동 저장하지 않습니다. 저장 버튼을 직접 누르면 `balance-plan-v2` 키에 검증된 건강 입력값·완료 날짜·10분 전환·계획 시작일만 보관합니다. 사진·식사 사진 파일·분석 기록은 저장 대상이 아닙니다.
- 저장은 마지막 저장 이후 30일 동안 유지됩니다. 저장을 켠 사용자의 계획 수정·완료 체크·재방문은 저장 기간을 갱신합니다. 암호화된 저장소나 계정 간 동기화가 아닙니다. 공용기기에서는 사용하지 말고 **내 입력과 기기 저장 모두 지우기**로 삭제할 수 있습니다.
- 사진은 JPEG/PNG/WebP, 8MB 이하만 메모리에서 미리 봅니다. 교체·삭제·페이지 이탈 때 객체 URL을 해제합니다. 브라우저나 기기 자체의 접근 통제를 대신하지 않습니다.
- GitHub Pages의 공개 저장소 무료 호스팅을 사용합니다. 사이트는 누구나 접속할 수 있으며 이용자 약 4명을 위해 유료 서버나 API를 추가할 필요가 없습니다. 호스팅 제공자는 일반적인 접속 기록을 처리할 수 있습니다.

## GPT가 수정할 위치

공개 저장소에는 아래 파일이 루트에 있습니다. 로컬 산출물 폴더에는 서비스 파일이 `dist/`에 있습니다. `verify.mjs`는 두 구조를 자동으로 인식합니다.

| 파일 | 역할 |
| --- | --- |
| `catalog.mjs` | 운동 이름·동작·식품 후보·공식 출처·제품 규칙 |
| `planner.mjs` | 입력 검증·목표 반영·예산 대안·회복을 고려한 일정·분량·기간 계산 |
| `meal.mjs` | 식사 상황·제외 식품·한 끼 피드백 |
| `storage.mjs` | 저장 허용 필드·형식 검사·30일 만료 |
| `app.mjs` | 화면 상태·입력 오류·완료·축소·기기 저장 동의·사진 수명 |
| `index.html` | 입력 폼·페이지 구조·정책 문구 |
| `styles.css` | 색·간격·반응형 디자인 |
| `verify.mjs` | 일정과 핵심 안전·기능의 회귀 검사 |

권장 수정 순서는 관련 모듈 편집 → `node verify.mjs` → 수정한 `.mjs`에 `node --check` → 브라우저 핵심 흐름 확인 → 공개 반영입니다. 디자인 변경은 CSS와 HTML부터, 추천 기준 변경은 근거와 테스트부터 확인합니다. 외부 프레임워크·패키지 설치는 필요하지 않습니다.

HTTP 서버로 정적 파일을 제공하세요. 파일을 직접 더블클릭하면 브라우저의 ES 모듈 정책으로 실행이 제한될 수 있습니다. Node 또는 Python의 로컬 서버를 사용할 수 있습니다.
