# 밸런스 플랜

[공개 사이트](https://whsxmfodl.github.io/balance-plan/) · [소스 저장소](https://github.com/whsxmfodl/balance-plan)

18세 이상 성인을 위한 무료 웰니스 계획 도구입니다. 65세 이상은 보행·균형·낙상 상태를 추가 확인합니다. 회원가입·서버·유료 API·외부 라이브러리가 없습니다. 모든 계산은 방문자의 브라우저에서 실행됩니다.

## 사용 흐름

1. 목표, 나이·키·현재 체중, 가능한 시간과 운동 방식을 입력합니다. 목표 체중과 체성분은 비워도 됩니다. 실제 건강 수치를 예시값으로 미리 채우지 않습니다.
2. 날짜별 시작 계획, 동작·횟수·휴식과 이유를 확인합니다. 근력·매트 운동에는 회복일이 있고, 운동 가능 시간은 채워야 할 분량이 아니라 상한입니다.
3. 바쁜 날에는 10분 계획으로 전환하고, 이번 7일 안에서 운동 날짜를 바꾸거나 완료를 체크합니다. 날짜 중복·지난 날짜·근력/매트 및 처음·복귀 러닝의 회복 간격을 검사합니다.
4. 아침·점심·저녁의 식사 장소와 이번 주 실천 행동을 선택해 하루 식사 초안을 만듭니다. 집밥·외식·편의점 식사 예시에서 피할 식품을 제외하고 단백질 식품을 바꿀 수 있습니다. 필요한 식품을 체크하고 실제로 먹은 끼니·구성과 평소 대비 양을 살펴 다음 한 끼의 선택을 안내합니다. 식약처 음식 자료 19,494건에서 영양정보를 검색하고, 실제 먹은 양을 아는 음식 최대 5개의 참고값을 합산할 수 있습니다.
   확인한 하루 열량과 가장 가까운 한국 식사구성안 B형을 선택하면 곡류·단백질 식품·채소·과일·유제품의 하루 기준 횟수와 밥 환산량을 볼 수 있습니다. 열량은 이 사이트가 추정하지 않으며, 공식 NIH 도구 링크를 사용자가 직접 열어 확인할 수 있습니다.
5. 한 주의 실행 횟수·걸림돌·통증을 직접 돌아보고 다음 주의 작은 조정을 봅니다.
6. 원할 때만 **이 기기에 기억하기**를 누릅니다. 이후 입력과 완료·10분 전환·변경한 날짜를 같은 브라우저에서 이어갈 수 있습니다.

## 정확도와 안전 범위

- `catalog.mjs`에 공식 근거 링크, 연구의 적용 범위, 제품이 정한 시작 규칙을 나눠 기록했습니다. 이는 의료 처방이나 개인별 효과가 검증된 추천 모델이 아닙니다.
- “체중 감소의 90%가 식단” 같은 고정 비율은 제시하지 않습니다. CDC는 먹고 마시는 선택의 변화가 체중 감소에 중요하며 운동에도 건강·체중 유지 역할이 있다고 설명합니다. 하루 식사 초안은 열량 적자나 감량 효과를 계산하지 않습니다.
- 분량 표는 보건복지부·한국영양학회의 2020 한국인 영양소 섭취기준 활용연구에서 제공하는 1회 기준량과 하루 열량별 식사구성안 B형입니다. 밥 210g은 곡류 1회 기준이지 모든 사람의 한 끼 처방량이 아닙니다. 식물성 식단·유제품 제한·건강 주의에는 이 표를 그대로 적용하지 않습니다. 환산 규칙은 `dist/portion-guide.mjs`에 있고 `node verify-portion.mjs`로 확인합니다.
- 체성분은 키·체중·푸시업·사진으로 추정하지 않습니다. 골격근량과 체지방을 제외한 체중의 모순을 검사합니다. 목표 체중을 비운 상태에서 목표 골격근량이 현재 체중 이상이면 수치 확인을 요청합니다.
- 임의의 주간 감량 속도를 넣어 예상 도착 날짜를 보여주지 않습니다. 사용자가 두 시점의 주간 평균 체중을 입력한 경우에만 관찰된 속도가 유지된다는 조건부 계산을 제공합니다. 단순 연장 결과가 52주를 넘으면 주 수 표시를 보류합니다. 52주는 장기 추정의 거짓 정밀도를 줄이기 위한 제품 정책이며 의학적 경계가 아닙니다. 정체기·체수분·개인 생리 변화를 모델링한 예측이 아닙니다.
- 푸시업 정보는 상체 운동 변형에만 사용합니다. 처음·복귀 사용자의 러닝 구간은 매일 반복되지 않습니다. 근육 목표 숫자가 크다고 자동으로 운동량을 크게 늘리지 않습니다.
- 근력 템플릿은 시작용 예시이며 각자의 모든 근육군·장비·기술을 완전히 평가하지 않습니다. 동작 교육과 개별 부하 조절은 대면 지도가 더 적합합니다.
- 65세 이상은 근력·균형을 보완하며, 낙상 우려 또는 보행 상태 불명·부담이 있으면 자동 계획을 보류합니다. 저체중 범위·건강상 주의·서비스 범위를 벗어나는 목표도 보류합니다. 15% 체지방률 목표와 25% 체중 변화 제한 등은 보수적인 제품 정책이며 보편적인 의학적 경계가 아닙니다.
- 18~64세의 같은 경험·능력·시간에 나이만 달라졌다고 임의의 운동량 계수를 곱하지 않습니다. 성별로 횟수·칼로리를 추정하지 않으며, 임신·수유는 별도 건강 확인에서 다룹니다. 나이로 폐경·호르몬 상태를 추정하지 않습니다.
- 65세 이상 활동일마다 균형 연습 2분을 기존 시간에 포함합니다. 이는 시작용 제품 규칙이고 권고 강도·분량 충족이나 낙상 예방 효과를 검증한 처방이 아닙니다. 주 1~2일만 가능하면 권고와의 차이를 설명합니다.
- 나이와 관계없이 바닥 동작 회피를 선택할 수 있습니다. 매트 필라테스와 충돌하면 서서 하는 맨몸 대안으로 바꾼 이유를 표시합니다.
- 알레르기 안전을 보장하지 않습니다. 식품 제외는 예시의 재료 수준이고 가공품·소스·교차접촉·목록 밖의 알레르기를 판별하지 못합니다.
- 음식 사진은 로컬 미리보기만 제공합니다. 자동 영양 분석, 신체 사진·영상 분석, 칼로리·목표 지연 날짜 추정은 구현하지 않았습니다.
- 음식 영양정보는 [식약처 제공 전국통합식품영양성분정보(음식)표준데이터](https://www.data.go.kr/data/15100070/standard.do)의 2026-08-28 CSV를 가공한 정적 사본입니다. 19,495행 중 문자 깨짐이 있는 1행을 제외했습니다. 수치는 각 행의 100g 또는 100ml 기준입니다. 사용자가 섭취량을 g 또는 ml로 직접 입력한 음식 최대 5개를 비례 환산해 합산합니다. 한 항목에 결측이 있으면 해당 영양소 합계는 표시하지 않습니다. 빠진 음식·소스·조리법을 알 수 없으므로 식사 전체 열량이나 목표에 미친 영향으로 해석하지 않습니다. 음식명·사진에서 양을 추정하지 않습니다. 가공식품 전체 목록은 포함하지 않습니다.

## 개인정보와 비용

- 건강정보·사진을 서버나 외부 AI에 전송하지 않습니다. CSP는 연결 요청과 폼 전송을 차단합니다. 외부 출처 링크는 방문자가 선택할 때만 새 탭에서 열립니다.
- 음식 검색 데이터는 사이트에서 제공하는 정적 모듈을 열 때만 불러옵니다. 검색어·선택한 음식·입력한 섭취량·합계는 외부로 보내거나 기기에 저장하지 않습니다. 건강 주의로 바꾸거나 전체 삭제를 누르면 현재 화면의 음식 합계도 지웁니다.
- 기본 상태에서는 건강정보를 자동 저장하지 않습니다. 저장 버튼을 직접 누르면 `balance-plan-v2` 키에 검증된 건강 입력값·완료 날짜·10분 전환·변경한 날짜·계획 시작일만 보관합니다. 사진·식사 사진 파일·분석 기록·오늘의 식사 장소와 실천 선택은 저장 대상이 아닙니다.
- 저장은 마지막 저장 이후 30일 동안 유지됩니다. 저장을 켠 사용자의 계획 수정·완료 체크·재방문은 저장 기간을 갱신합니다. 암호화된 저장소나 계정 간 동기화가 아닙니다. 공용기기에서는 사용하지 말고 **내 입력과 기기 저장 모두 지우기**로 삭제할 수 있습니다.
- 새 건강 주의·고령 균형/보행 주의를 입력하거나 계획이 보류되면 이전 기기 저장을 지웁니다. 새로고침 후 오래된 추천이 복원되지 않도록 하기 위함입니다. 저장된 나이가 바뀌었다면 직접 수정해야 합니다.
- 사진은 JPEG/PNG/WebP, 8MB 이하만 메모리에서 미리 봅니다. 교체·삭제·페이지 이탈 때 객체 URL을 해제합니다. 브라우저나 기기 자체의 접근 통제를 대신하지 않습니다.
- GitHub Pages의 공개 저장소 무료 호스팅을 사용합니다. 사이트는 누구나 접속할 수 있으며 이용자 약 4명을 위해 유료 서버나 API를 추가할 필요가 없습니다. 호스팅 제공자는 일반적인 접속 기록을 처리할 수 있습니다.

## GPT가 수정할 위치

공개 저장소에는 아래 파일이 루트에 있습니다. 로컬 산출물 폴더에는 서비스 파일이 `dist/`에 있습니다. `verify.mjs`는 두 구조를 자동으로 인식합니다.

| 파일 | 역할 |
| --- | --- |
| `catalog.mjs` | 운동 이름·동작·식품 후보·공식 출처·제품 규칙 |
| `planner.mjs` | 입력 검증·목표 반영·예산 대안·회복을 고려한 일정·분량·기간 계산 |
| `meal.mjs` | 하루 식사 초안·식사 상황·제외 식품·한 끼 피드백 |
| `review.mjs` | 실행 횟수·걸림돌·통증에 따른 다음 주 조정 |
| `food-search.mjs` / `food-data.mjs` | 음식명 검색·추가 결과·명시한 양의 산술 환산과 결측 전파 합계 / 공개 음식 영양정보 정적 사본 |
| `import-food.mjs` | 공공데이터포털 음식 CSV를 검증·정리해 정적 모듈 생성 |
| `schedule.mjs` | 날짜 이동·중복·주 범위·회복 간격 검증 |
| `storage.mjs` | 저장 허용 필드·형식 검사·30일 만료 |
| `app.mjs` | 화면 상태·입력 오류·완료·축소·기기 저장 동의·사진 수명 |
| `index.html` | 입력 폼·페이지 구조·정책 문구 |
| `styles.css` | 색·간격·반응형 디자인 |
| `verify.mjs` | 일정과 핵심 안전·기능의 회귀 검사 |
| `verify-meal.mjs` | 540개 식사 상황·선호·식품 제한 조합 |
| `verify-review.mjs` / `verify-food.mjs` | 주간 조정 안전 조건 / 음식 자료·검색·결측 검증 |
| `verify-schedule.mjs` | 날짜 변경 1,176건 및 회복·저장 검사 |
| `PRODUCT.md` / `DESIGN.md` | 제품 제약·디자인 토큰·상태·반응형 구조 |
| `simulate.mjs` | 남성 10명·여성 10명의 가상 생활 시나리오 검사 |
| `audit-simulate.mjs` / `simulation-results.json` | 고정 시드의 가상 프로필 5만 개와 음식 합계 1천 건 점검 / 집계 결과 |

권장 수정 순서는 관련 모듈 편집 → `node verify.mjs`, `node simulate.mjs`, `node verify-schedule.mjs`, `node verify-meal.mjs`, `node verify-review.mjs`, `node verify-food.mjs` → 수정한 `.mjs`에 `node --check` → 브라우저 핵심 흐름 확인 → 공개 반영입니다. 음식 데이터를 갱신할 때는 공식 CSV를 내려받아 `node import-food.mjs <CSV 경로>`를 실행하고, 생성된 건수·결측·대표 음식 검색을 확인합니다. 디자인 변경은 CSS와 HTML부터, 추천 기준 변경은 근거와 테스트부터 확인합니다. 외부 프레임워크·패키지 설치는 필요하지 않습니다.

HTTP 서버로 정적 파일을 제공하세요. 파일을 직접 더블클릭하면 브라우저의 ES 모듈 정책으로 실행이 제한될 수 있습니다. Node 또는 Python의 로컬 서버를 사용할 수 있습니다.

## 검증 기록 · 2026-09-28

- 30·65·80세를 포함한 6,510개 일정 조합에서 회복 간격(주 경계 포함), 시간 상한·블록 합계·세트 시간, 균형 연습, 10분 축소를 확인했습니다.
- 가상의 남성 10명·여성 10명은 17명 시작 계획, 3명 확인 후 진행으로 예상 동작과 일치했습니다. 실제 사용자·임상 데이터가 아닙니다.
- 빈 예산·모순된 체성분·위험 조건·선택 입력·목표 반영·시설 요금·식사 제외·기록 기반 기간·저장 허용 필드와 만료를 검사합니다.
